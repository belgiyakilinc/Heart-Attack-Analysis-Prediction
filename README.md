# Heart-Attack-Analysis-Prediction

Bu proje, kalp krizi riskini analiz etmek ve tahmin etmek için makine öğrenimi tekniklerini kullanmaktadır. Veri yükleme ve temizleme adımlarıyla başlayan analiz, çeşitli görselleştirmelerle (kutu grafikleri, swarm grafikleri, korelasyon ısı haritaları) veri dağılımını ve değişkenler arası ilişkileri incelemektedir. Aykırı değer tespiti yapıldıktan sonra, kategorik özellikler kodlanmış ve sayısal özellikler standartlaştırılmıştır. Son olarak, Lojistik Regresyon modeli eğitilmiş, performansı değerlendirilmiş ve hiperparametre ayarlaması yapılmıştır. Kodlar ve çıktılar, tüm bu adımların detaylı bir şekilde nasıl uygulandığını göstermektedir.

his project focuses on analyzing and predicting heart attack risk using machine learning techniques. Starting with data loading and cleaning, the analysis delves into data distribution and inter-variable relationships through various visualizations such as box plots, swarm plots, and correlation heatmaps. After outlier detection, categorical features are encoded, and numerical features are standardized. Finally, a Logistic Regression model is trained, its performance is evaluated, and hyperparameter tuning is performed. The code and outputs demonstrate a detailed implementation of all these steps.
